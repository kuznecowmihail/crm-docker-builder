# Работа с Keycloak

При запуске проекта для всех CRM создаётся один пользователь Keycloak. Пароль каждого стенда запоминать не нужно и входить в каждую CRM отдельно тоже не нужно: залогинились в Keycloak один раз и дальше открываете остальные CRM этого проекта уже без повторного ввода пароля.

При запуске проекта для всех стендов пароль пользователя Supervisor в CRM сбрасывается на Supervisor. В Keycloak создаётся пользователь Supervisor с паролем Supervisor.

Сессия хранится в браузере на стороне Keycloak. У каждой CRM свой OpenID-клиент, пользователь один на весь проект.
